# Connect4 Multiplayer

Real-time multiplayer Connect4 game built with Go, React, TypeScript, WebSockets, JWT Authentication, and Elo Ranking.

## Features

- Real-time multiplayer gameplay
- Matchmaking system
- Spectator mode
- Elo ranking
- JWT Authentication
- Google OAuth
- AI Bot (Minimax + Alpha-Beta Pruning)
- Game history tracking
- Reconnection recovery

## Tech Stack

- Go
- React
- TypeScript
- PostgreSQL
- Redis
- WebSockets
- Docker
